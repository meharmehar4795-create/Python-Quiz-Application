# Quiz Application 🎯

A simple and interactive Quiz Application built using Python and Tkinter.

## Features
- User name input
- Multiple quiz categories
- Random questions
- 10-second timer
- Progress bar
- Score calculation
- Answer checking
- Leaderboard
- Play Again and Exit options

## Technologies Used
- Python
- Tkinter

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the Python file.
4. Start the quiz and enjoy!
